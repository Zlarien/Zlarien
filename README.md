### 👤 Identity

> **"I don't just use AI tools — I build with them, document everything, and teach others to do the same."**

Today I build **AI-powered tools** and document the whole process publicly on **[BuildAIToday](https://github.com/Zlarien/BuildAIToday)** — a living lab where curiosity meets engineering.
